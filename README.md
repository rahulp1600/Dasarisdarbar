# Dasari Darbar — Veg & Non Veg Family Restaurant

Authentic Indian flavours, family-style dining, digital QR menu, smart dine-in reservations, and an AI-powered OCR bill loyalty program for Dasari's Darbar, Kothapet, Hyderabad.

---

## Live Services

* **Frontend Web App (Vercel):** React + Vite SPA
* **Backend API & OCR Service (Render):** [https://dasarisdarbar.onrender.com](https://dasarisdarbar.onrender.com)
* **Database & Authentication:** Supabase Cloud

---

## Features

- **Royal Theme & Modern Dining UI:** Fully responsive design with mobile-first bottom navigation.
- **Master 160+ Dish Menu:** Live categorized menu with veg/non-veg tags, real-time availability, and high-resolution visuals.
- **AI/OCR Bill Loyalty Program:**
  - Automated receipt scanning and verification via OpenCV and Tesseract OCR.
  - Track 1: Milestone visits streak counter (5 visits -> reward voucher).
  - Track 2: High-value dining bills (₹2,000+ -> instant coupon with counter physical bill verification).
  - Anti-fraud guards: daily sequence validation, duplicate fingerprint check, and anomaly review queue.
- **Comprehensive Admin Panel:** Menu editor, customer rewards directory, table booking management, and daily sequence controls.
